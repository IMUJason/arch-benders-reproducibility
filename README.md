# ARCH-Benders: Exact Hybrid Benders with Ranked Probing
## Minimal Reproducibility Package for C&OR Submission

This package contains the core implementation of ARCH-Benders, an exact hybrid Benders decomposition framework for stochastic network design problems.

**Reference Paper:** ARCH-Benders: Exact Hybrid Benders with Ranked Probing for Stochastic Network Design

**Corresponding Author:** Jin Xin Cao (imucjx@163.com)

---

## Quick Start

### Installation

```bash
# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### Run a Simple Example

```bash
cd experiments
python run_pilot_study.py
```

## Core Algorithms

### Classical Multicut Benders
The baseline algorithm that generates Benders cuts from all scenarios at each major iteration.

### ARCH-Benders (Hybrid)
An exact hybrid framework that:
1. Maintains the restricted master as the sole source of certified lower bounds
2. Uses a budgeted auxiliary search layer to propose additional first-stage designs
3. Applies ranked probing to identify which scenarios deserve exact evaluation

The ranking score combines:
- **Anchor underestimation mass**: Immediate bound improvement potential
- **Cut sensitivity**: Future effectiveness based on master solution stability

## Instance Generation

Stochastic network design instances are generated using:

```python
from src.instance_generation import generate_instance

instance = generate_instance(
    num_facilities=24,      # First-stage decision variables
    num_customers=36,       # Second-stage customers per scenario
    num_scenarios=60,       # Number of scenarios
    capacity_seed=42,       # Random seed for capacities
    demand_seed=43          # Random seed for demands
)
```

## Understanding the Results

Results are generated by running the experiment scripts. Each experiment outputs CSV files containing iteration logs and performance metrics.

### Key Metrics

| Metric | Description |
|--------|-------------|
| `major_iters` | Number of Benders major iterations |
| `total_subprob_time` | Time spent solving subproblems |
| `master_time` | Time spent solving the master problem |
| `total_time` | Total wall-clock time |
| `final_lb` | Final lower bound (certified optimal) |
| `final_ub` | Final upper bound (best feasible solution) |
| `gap` | Optimality gap at termination |
